# Agent Guiding Principles

一套面向通用 AI Agent 的工作原则，用于让执行、判断与沟通建立在一致的决策标准上。

## 定位

这份 `AGENTS.md` 是跨项目的行为与决策基线，重点约束 Agent **如何思考和取舍**，而不是规定具体技术栈、代码风格或项目命令。

它主要解决五类问题：

- 为了快速完成当前任务而积累长期维护成本；
- 以未来扩展为由进行缺乏依据的过度设计；
- 未验证前提便沿用用户或既有系统给出的路径；
- 信息不足时盲目推进，或遇到轻微不确定性便频繁中断；
- 为迎合预期而回避明确判断、风险和事实冲突。

核心取向是：在目标和约束明确的前提下，选择全生命周期成本更低、概念更少、边界更清晰且更容易验证的方案。

## 适用范围

- 软件设计、实现、重构和技术决策；
- 问题分析、方案比较与任务执行；
- 需要识别 XY 问题、隐含假设或路径依赖的场景；
- 希望 Agent 主动指出明显更优路径，但避免无意义反驳的协作方式。

## 不替代什么

它不替代项目级规范、安全策略、测试要求或领域知识。具体项目仍应在仓库内提供更贴近代码和业务的 `AGENTS.md`，补充构建命令、架构约束、验证方式及禁止事项。

## 使用方式

- 作为个人全局规则：保存为 Codex 主目录下的 `AGENTS.md`。
- 作为项目规则：保存到仓库根目录，并按项目需要补充具体约束。
- 作为团队基线：保留通用原则，将技术栈与业务规则放在项目级或子目录级文件中。

建议定期删除无法影响实际决策的口号式规则，只保留能够改变行为、验证结果或降低风险的约束。
