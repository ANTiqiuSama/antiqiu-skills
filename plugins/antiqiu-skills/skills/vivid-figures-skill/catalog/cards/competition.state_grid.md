# 108 · 离散状态时间栅格

ID：`competition.state_grid`

用途：单元状态随帧或时隙如何切换？

标签：时间、矩阵、仿真

别名：state grid、状态矩阵、时隙仿真

## 数据要求

- 单元×时间的离散状态编码矩阵
- 类别解释

## 组合结构

每单元一行；每时隙一列

## 视觉特点

- 离散色块
- 细白格线
- 状态色条

## 适配注意

颜色编码类别或等级，不适合连续插值；状态0可能代表成功而非无数据。
