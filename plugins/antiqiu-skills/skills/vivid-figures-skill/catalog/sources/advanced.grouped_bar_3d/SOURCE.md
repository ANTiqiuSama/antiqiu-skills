## 适配内容

用途：比较两组离散条件交叉组合下的非负测量值，例如材料×掺量、算法×实验条件。
输入：行标签、列标签、对应高度矩阵；可选真实误差长度。CSV 第一列为行标签，第一行为列名。
保留：四面分层渐变柱、独立顶面明暗、正交视角、柱顶数值、误差竖线与帽线、白底虚线网格、同分档侧色条。
配色：从项目 palette_colors() 的原顺序插值为分档颜色，分类取色顺序不用于数值分档；不改变柱面的原有提白曲线。
示例：66个柱高转录自用户参考图；误差棒为原复现的示意长度，已在预览标注，并非真实实验误差。自定义数据未提供误差时不生成误差棒。
适配：plot_chart 支持 (行,列) 对称误差或 (2,行,列) 非对称误差；负值、缺失值与越界色档直接报错，不能填零或静默截断。默认新数据使用线性分档；示例保留原不等宽阈值，色条等高色块代表档位而非线性距离。
局限：三维遮挡会影响密集类别比较；组数过多可按任务减少同屏项或调整视角。该模板不是频数直方图，也不表示连续曲面。

当前模板保留原复现几何、渐变指数0.65、40层侧面、面明暗系数、正交视角及文字样式。新增数据校验、动态行列数与坐标范围、项目配色、独立误差输入和可复用函数；未调整共享配色算法或其他模板。

## 使用

在已初始化的 Vivid 工作区运行完整代码，默认输出示例 PNG / PDF：

```text
python original.py
python original.py --data values.csv --errors errors.csv --value-label "Strength /MPa" --output figures/fig_strength
```

两个CSV都采用 `Sample,Condition-A,Condition-B,...` 的宽表布局，行列标签和顺序必须完全一致；CLI误差CSV为对称长度。没有误差数据时省略 `--errors`。非对称误差通过 `plot_chart(..., errors=array)` 传入下/上长度数组，不是区间端点。

当前配色从 `.vivid/config.json` 读取，未配置使用橄榄杏棕。依赖 NumPy、Matplotlib 及随包 Vivid 工具；源码位于完整安装包中时可直接运行。
