#### 场景示意图 (fig_scene.png)

仅适用于有具体物理/工程空间场景的赛题（光学、无人机、传感器、交通、热传导等）。
纯数据/统计类赛题不需要。

助手 根据赛题自由构造 prompt，参考格式：

```
生成一张学术论文插图风格的{场景名}示意图。
{俯视/侧视/3D等距}视角。
画面包含：{元素1}、{元素2}、{元素3}。
用虚线箭头表示{某种关系/流向}，用不同颜色区分{不同类别}。
包含图例说明各颜色含义。
```

⛔ 约束：
- 不超过 6 个视觉元素
- 不生成真人面孔/肖像——需要人物时用抽象图标
- 必须包含图例框解释颜色含义
- 尺寸标注用数学变量（R, H, L）不用具体数字
