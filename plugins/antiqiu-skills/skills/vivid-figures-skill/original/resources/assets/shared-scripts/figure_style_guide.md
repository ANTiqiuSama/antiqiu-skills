# 绘图知识索引

按当前步骤读取相关资源；无需顺序读完整套文件。选定模板后以其完整源码、卡片保留要点和真实数据为适配依据。

| 何时需要 | 资源 |
|---|---|
| 选图时需要数据形态对照 | [决策表](figure_selection_reference.md)；优先使用包内 catalog/selection-index.jsonl 和候选实图 |
| 配色角色、连续色阶及图型用色 | [配色](figure_color_reference.md)；具体颜色唯一维护在 palettes.json |
| figsize 与最终显示尺寸、面板、字号、图例和防遮挡 | [布局与可读性](figure_layout_reference.md) |
| 已选图需要有依据的统计层、对数零值或局部技法 | [局部技法](figure_techniques.md) |
| TikZ 结构图 | [TikZ 完整布局模板](tikz_layout_templates.md) |

这些是同一套指导的按需资源，没有增加绘画风格或模板分组。固定图型配额不适用；必要重复支持一致比较。检查与修复轮次由 skill 的 original/review-policy.md 统一规定。
