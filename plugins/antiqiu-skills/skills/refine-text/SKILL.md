# Refine Text

For academic or professional prose, read and use [academic-humanizer](../academic-humanizer/SKILL.md) before polishing, including prose produced during the current task. This skill does not define a second house style. Use [document-writing.md](references/document-writing.md) only for routing, fidelity and the actual output format.

For other text, follow the user's requested purpose, language, format and revision scope. Ordinary rewriting needs no plan or extra approval; ask only when a missing choice materially changes the result.

Preserve units, denominators, populations, conditions, negation, uncertainty, conflicting evidence, links and technical notation. Never invent facts, citations, commitments or certainty. Pure translation remains a fidelity task; apply academic-humanizer only to an authorized polishing pass.

Substantive judgment—causes, recommendations, disputed evidence or research interpretation—stays with the current task. Prose output alone does not justify switching models or delegating reasoning. Track complex dependencies internally only when useful.

Check changed passages against their sources and inspect actual rendering when the output requires it. Reuse valid checks. Do not impose a fixed number of full reviews, a text test harness or routine file/backup hashing. Hash checks require an actionable integrity, security or protocol-binding question. If support is insufficient, identify the material gap without inventing it away.

Return the requested revised text or artifact. Honor final-copy-only requests; otherwise follow academic-humanizer's applicable change-report contract. Publish, send or share only within explicit authorization.
