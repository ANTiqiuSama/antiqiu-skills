# 文本润色入口与格式保真

论文、专业说明、技术文档及其他专业文本的语言润色，必须先读取并使用 [academic-humanizer](../../academic-humanizer/SKILL.md)；起草后的润色同样适用。本文件不再规定独立文风、措辞、段落节奏或修辞偏好。普通答复和非专业文本按用户本轮要求处理；纯翻译、原文引述、代码及机器可读内容保持其任务契约。

保留原意、数字、单位、比较对象、时间、引用、否定、不确定性与冲突，不新增证据或加强结论。代码、链接、标识符、公式和用户要求保留的原文不按普通文案改写。

严禁无用的哈希检查。普通文本编辑、润色、文件回读与备份不例行计算或展示哈希；只有明确的完整性、安全或协议版本绑定问题需要据此作出后续决定时才检查最小相关范围。文字改动用实际内容及适用渲染核对，哈希一致不能证明文字质量或功能正确。

## 公式与版面

按目标媒介支持的数学语法或对象表示公式。`<latex>...</latex>` 只在环境实际支持时保留；可阅读交付不能用未渲染标签或代码框冒充公式，要求源码时交付源码。

- Markdown/网页：核实实际渲染支持，显示公式水平居中，行内式与基线协调。
- Word：沿用对应文档技能与原有数学表示；需要可编辑时使用原生对象。允许图片而无可靠原生路径时用清晰渲染图并说明编辑限制，不用空格凑居中。
- PDF/LaTeX：使用实际支持的编辑器或项目排版流程，核公式编号、断行、缺字、裁切与对齐。

保留上下标、分式、括号、向量、求和范围、定义和单位，说明靠近公式。格式化文件检查最终渲染的标题、段距、分页、表格、图注、页码与混排；文本或 XML 回读不能代替版面证据。未能渲染就说明具体缺口，由有权限的执行者完成，不扩大文本 worker 权限。

## 必要复核

按修改范围核对原意、数字、公式、引用和格式接口。复用未受影响的验证，不规定全文通读次数；实际问题才触发追加检查。只报告真实验证，用户只要正文时只交付正文。
